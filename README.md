# Walnut67

This project was inspired by Walnut53, a basic substitution cipher used in the paper [Covert Malicious Finetuning: Challenges in Safeguarding LLM Adaptation by Halawi et. al](https://arxiv.org/pdf/2406.20053), published in ICML.

This paper used a substitution cipher to generate a "secret language" as a backdoor to work around security mechanisms in LLMs. The cipher, Walnut53, wasn't made public, but this can be replicated using the cipher in this project.
